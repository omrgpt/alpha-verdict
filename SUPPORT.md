# Support

Use the right channel so maintainers can respond effectively:

- **Bug with a synthetic reproduction:** open a bug report.
- **Design or feature proposal:** open a feature request and explain the research job.
- **Question about usage:** start a GitHub Discussion when enabled.
- **Security vulnerability:** report privately under [SECURITY.md](SECURITY.md).

Support does not include evaluating a security, validating a private trading idea,
supplying licensed data, interpreting results as investment advice, or helping deploy
capital.

Before asking, run `alphaverdict validate`, search existing issues, and reduce the
problem to the smallest synthetic fixture that preserves it.
