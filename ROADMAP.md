# Roadmap

AlphaVerdict’s roadmap is ordered by research validity, not feature count.

## 0.1 — Foundational contracts

- [x] bitemporal multimodal data bundle
- [x] current screen and causal portfolio backtest
- [x] deterministic audit council and stable findings
- [x] local reports, manifests, strict CLI, and synthetic proof
- [x] security policy, threat model, tests, and release automation

## 0.2 — Conformance and comparison

- [ ] public adapter conformance kit with seeded temporal traps
- [ ] run-to-run report diff and finding regression policy
- [ ] delisting/corporate-action reference fixtures
- [ ] calendar and exchange-session adapter contract
- [ ] machine-readable JSON Schemas for configuration and artifacts

## 0.3 — Stronger research design

- [ ] walk-forward estimator hook with fit/predict time barriers
- [ ] embargoed and purged evaluation primitives where labels overlap
- [ ] complete experiment ledger for trial-count provenance
- [ ] richer liquidity, capacity, sector, and benchmark stress reviewers
- [ ] independent strategy holdout protocol

## 1.0 criteria

- stable data, strategy, finding-code, and artifact schemas;
- multiple independently maintained adapters passing conformance;
- externally reproduced reference runs across operating systems;
- documented migration policy and at least two pre-1.0 compatibility cycles;
- evidence from recurring real users that the core job is being solved.

## Explicitly out of scope

Broker connections, live orders, automatic capital deployment, bundled proprietary
data, performance guarantees, opaque stock-picking agents, and non-stock asset
classes. Proposals to change these boundaries require an ADR and maintainer consensus.
